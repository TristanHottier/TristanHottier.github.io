# tristanhottier.github.io

This is the source of my personal website: **https://tristanhottier.github.io/**

I'm Tristan, an aerospace M.Eng. student at UC Berkeley, on a double degree with CentraleSupélec. Most of what I've built so far is rockets, so that's most of what's here:

- **[Two-stage rocket](https://tristanhottier.github.io/projects/two-stage-rocket.html):** I designed its pneumatic stage-separation system. The rocket won Best Experimental Rocket at C'Space 2025.
- **[ARES, fin-controlled rocket](https://tristanhottier.github.io/projects/fin-controlled-rocket.html):** I was GNC lead. It flew twice with roll control. There's also a [paper on the GNC design](https://tristanhottier.github.io/assets/fin-controlled-rocket/gnc-design-paper.pdf).
- **[Self-landing rocket prototype](https://tristanhottier.github.io/projects/self-landing-rocket.html):** a thrust-vector-control prototype. I led the mechanical design.
- **[Berkeley capstone](https://tristanhottier.github.io/projects/capstone-vtol.html):** a hybrid VTOL drone, still in design.
- **[Black hole simulation](https://tristanhottier.github.io/projects/black-hole-simulation.html):** a real-time general-relativistic renderer you can [play with in the browser](https://tristanhottier.github.io/BH_Sim/).
- **[Electric utility vehicle](https://tristanhottier.github.io/projects/electric-utility-vehicle.html):** my father and I built it from scratch in 2018, and it is still in regular use.
- **[Loop Fitness](https://tristanhottier.github.io/projects/loop-fitness.html):** a workout tracker I built for my own training.

My CV is [here](https://tristanhottier.github.io/Tristan_Hottier_Resume.pdf).

The site is plain HTML and CSS: no framework and no build step.
