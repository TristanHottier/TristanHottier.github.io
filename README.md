# tristanhottier.github.io
Static one-page site, no build step. Edit `index.html` and `style.css`, commit, push to `main`; GitHub Pages publishes it. `/BH_Sim/` is a separate repo.
Quarterly update: replace `Tristan_Hottier_Resume.pdf` (same filename), then check the "Available" badge and each card against the CV.
Photos/video: save to `assets/` (e.g. `assets/x4.jpg`), then in `index.html` find `<figure class="media" id="media-x4">` (ids `media-x2`, `-x3`, `-x1`, `-x6`, `-x7`) and replace the `<svg>` with the `<img>` shown in the HTML comment above it.
X1 (capstone) is confidential: use only a neutral image, never team or sponsor files.
