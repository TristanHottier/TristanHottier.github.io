Loop Fitness

Personal project · 2026

Loop Fitness is an installable workout tracker I built for my own resistance-band training plan. I use it on my Android phone, the app is live, and the code is public.

The problem

Gym trackers count in kilograms, but resistance bands come in discrete levels, and the resistance rises as they stretch. So Loop Fitness uses the band as the unit. It builds a resistance ladder from the bands I own and bases progression on that ladder. It tells me when to move up a band.

Main features

Training

  • A 4-day program with weekly volume targets for each muscle.
  • Fast logging: one line per set for reps and band, with reps in reserve in one tap.
  • A rest timer that keeps running with the screen locked.
  • The last session’s sets shown on every exercise.

Progression

  • A band inventory that builds the ladder, including stacked bands.
  • Per-exercise rules for when to move up or down a band.
  • Plateau detection that suggests a deload week.

Tracking

  • Weekly sets per muscle against its target, with a muscle-volume map ported from the open-source MuscleMap project (MIT).
  • Body weight and arm measurements, plus daily calories and protein, with charts.

Data

  • Works offline. Sync across devices is optional, through a Cloudflare Worker and D1.
  • JSON backup and restore, CSV export and daily weigh-in push reminders.

How I built it

I built it milestone by milestone with AI coding agents (OpenCode) and recorded each milestone in the repository. Unit tests cover the progression engine and the band ladder.
