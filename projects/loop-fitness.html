Loop Fitness

Personal project · 2026

Live appCode

Overview

I built Loop Fitness, an installable web app (PWA), to track my own resistance-band training plan, and I use it myself. I built it with an agentic AI coding workflow (OpenCode).

Features

  • A plan of 4 workouts and 29 exercises.
  • Session logging (bands, reps) with a rest timer.
  • Progress tracking for weight and arm measurements.
  • A muscle-volume map ported from the open-source MuscleMap project (MIT).
  • A nutrition tab, data sync and push reminders.
